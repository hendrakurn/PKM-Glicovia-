# GLICOVIA Express Brand System

GLICOVIA Express uses an editorial medical language inspired by SorollaPortfolio without copying its assets, layout, or brand. The product should feel calm, patient-first, and unusually deliberate for a health dashboard.

## Palette

- Canvas: `#FBF8EF`, an off-white clinical paper tone.
- Ink: `#17130F`, used for outlines, primary text, and key controls.
- Surface: `#FFFDF6`, used for panels and form fields.
- Mint: `#CCE8D7`, the primary health accent.
- Sky: `#CDDFF4`, a secondary trust and model-context accent.
- Butter: `#F3DF91`, a restrained attention accent.
- Coral: `#F0B39D`, used sparingly for cautions.
- Red: `#A8342D`, reserved for destructive/error states with AA contrast.

## Typography

- Brand and UI type: Manrope, chosen for confident rounded editorial forms without default SaaS familiarity.
- Technical and context type: JetBrains Mono, used for IDs, tokens, model versions, timestamps, and precise values.
- Display type remains tight in measure but uses normal letter spacing. Oversized type appears only for the current reading.

## Shape And Rhythm

- Panels use 8px radius, 2px black outlines, and a small offset ink shadow.
- Sections are modular blocks with strong borders, not floating glass cards.
- Accent blocks are pastel, flat, and purposeful: patient status, trust context, or operator distinction.
- Charts and lists use clear data hierarchy instead of ornamental decoration.

## Motion

- Use short entrance reveals and row transitions only where they help orientation.
- Live freshness uses a small pulse indicator.
- All motion respects `prefers-reduced-motion`.
