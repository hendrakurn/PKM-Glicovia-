# Project: Non-Invasive Blood Glucose Monitoring via Saliva (PKM-KC)

## Overview
Sistem prediksi kadar gula darah non-invasive menggunakan parameter saliva
(pH, viskositas, kandungan glukosa saliva) sebagai alternatif metode invasive
(glukometer konvensional). Tujuan: monitoring berkala dan berkelanjutan yang
mudah dan tidak menyakitkan, diakses lewat website.

## Team
- Saya: software (ML model + web monitoring, fullstack)
- Rekan: hardware (sensor alat, pengiriman data ke sistem)

## Data
- Jumlah sampel: ~150 data (akan bertambah seiring pengumpulan data lanjutan)
- Sumber: alat prototype hardware milik rekan tim
- Kolom: subject_id, sampling_date, sampling_time, fasting_hours,
  bg_reference_mgdl (target/ground truth dari glukometer), bg_category,
  saliva_ph, saliva_viscosity_sec, saliva_glucose_mgdl, proto_glucose_raw

## ML Approach
- Task: regresi — prediksi bg_reference_mgdl dari parameter saliva
- Model utama: SVR (Support Vector Regression)
- Kernel yang dieksplorasi: linear (baseline), rbf, poly
- Tantangan: dataset kecil (~150 sampel) — wajib pakai k-fold cross-validation,
  waspada overfitting, pertimbangkan feature scaling (SVM sensitif terhadap skala)
- Metrik evaluasi: RMSE, MAE, R² (standar untuk regresi continuous value medis)
